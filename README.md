# StudyDot

StudyDotは、勉強配信者向けのローカルファーストなデスクトップアプリです。学習時間と休憩を操作する画面、視聴者に見せる情報を編集する画面、OBS Browser Source用のオーバーレイをひとつにまとめています。

現在はWindows向けのベータ版を公開しています。macOS版の公開は、Apple署名と公証を準備できるまで停止しています。データは端末内に保存され、アプリの画面とOBS表示の通信もローカルホスト内で完結します。

## ダウンロード

ベータ版は[StudyDot公式サイト](https://studydot.app/)からダウンロードできます。配布物はCloudflare R2に置き、サイトから直接取得できるようにします。

- Windows：x64用インストーラー

現時点の配布物にはコード署名を行っていません。WindowsではSmartScreenの警告が表示される場合があります。初めて使う場合は、サイトに記載する起動手順も確認してください。

## 現在の機能

### 学習タイマー

- 状態に応じて学習開始・一時停止・再開が切り替わる主操作ボタン
- 学習・休憩タイマーを、それぞれ一時停止・再開
- 学習時間と休憩時間を時・分・秒で設定
- インターバル終了時に学習と休憩を自動で切り替えるモード
- 学習・休憩の終了を知らせる、ON/OFF可能な通知音
- 開始後、今日、累計の学習時間を記録
- 配信外で行った学習時間を今日と各期間の集計へ追加

### 視聴者向けボード

- 状態、残り時間、状態別メッセージ、常時表示する注記の表示・非表示
- 状態別メッセージの定型文選択と自由入力
- 開始後、今日、今週、今月、今年、累計、カスタム項目を個別に表示・非表示
- 集計時間の秒表示を任意で有効化
- 日数または回数を扱える「カスタム項目」を複数登録（初期サンプルは筋トレ回数）
- 日数項目は毎日・平日・休日・任意の曜日からカウント対象を選択
- 複数のカスタム項目をまとめて表示
- 日本語・英語の視聴者表示
- 横長・縦長レイアウト
- ダーク・ライト・カスタム配色、背景・メイン文字・補助文字の色と不透明度、補助文字のコントラスト目安
- 編集画面での視聴者表示プレビュー

視聴者向け言語の設定はOBS表示だけに適用され、配信者が操作する画面は日本語のままです。

マイクを使う自動停止機能は検証用コードとして切り離してあり、現在の公開ベータにはUI・モデル・ONNX Runtimeを含めません。

### OBS連携

アプリ起動中、次のURLをOBSのBrowser Sourceへ登録します。

```text
http://127.0.0.1:47831/overlay
```

推奨サイズはアプリ内の「OBSへ追加」画面にも表示されます。

| レイアウト | 推奨サイズ |
| --- | --- |
| 横長 | 600 × 180 px。配信外学習または注記を表示するごとに高さを52 px追加 |
| 縦長 | 320 × 520 px |

サーバーは`127.0.0.1`だけで待ち受けるため、LANやインターネットには公開されません。アプリを終了するとOBS表示も停止します。

## データ保存

デスクトップアプリでは、状態と設定をOS標準のアプリデータフォルダにある`state.json`へ保存します。

- macOS：`~/Library/Application Support/app.studydot.desktop/state.json`
- Windows：`%APPDATA%\\app.studydot.desktop\\state.json`

旧StudyStream開発版の保存先がある場合は、初回起動時に状態とウィンドウサイズをStudyDotの保存先へコピーします。

書き込み途中の破損を避けるため、一時ファイルへ書いてから置き換えます。タイマーは開始・終了時刻から画面側で計算し、操作時と15秒ごとの復旧用チェックポイントで保存します。毎秒ディスクへ書き込むことはありません。

`npm run dev`で起動する開発用サーバーだけは、リポジトリ内の`data/state.json`を使用します。`data/`の状態ファイルはGitの管理対象外です。

## 開発

Node.js、npm、Rust、およびTauri 2のビルドに必要なOS別ツールを準備してください。

依存関係をインストールして、Web画面とローカルサーバーを起動します。

```bash
npm install
npm run dev
```

- 開発画面：`http://127.0.0.1:5173/`
- 開発中のOBS表示：`http://127.0.0.1:5173/overlay`
- 保存API：`http://127.0.0.1:47831/`

本番用のWebアセットとローカルサーバーを確認する場合：

```bash
npm run build
npm start
```

- 操作画面：`http://127.0.0.1:47831/`
- OBS表示：`http://127.0.0.1:47831/overlay`

型チェック、テスト、Webビルドは次のコマンドで実行できます。

```bash
npm run check
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

## デスクトップアプリのビルド

開発版を起動する場合：

```bash
npm run desktop:dev
```

配布用バンドルを生成する場合：

```bash
npm run desktop:build
```

macOSでは`src-tauri/target/release/bundle/macos/StudyDot.app`とDMGが生成され、手元での起動確認用にアドホック署名されます。一般配布で警告を減らすには、別途Apple Developer IDによる署名と公証が必要です。Windowsでは同じソースからWindows用バンドルを生成します。

アプリは同時に複数起動できません。また、`47831`番ポートを別のアプリが使用している場合は起動できません。
