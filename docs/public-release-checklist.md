# Public release checklist

StudyDotを一般公開する前の最小確認項目です。機能追加の管理表ではなく、配布事故を防ぐためのチェックだけを扱います。

## 現在確認できていること

- GitHubリポジトリはPublic
- MITライセンスと第三者ライセンス表記を同梱
- 完成版`0.1.0`の前に、`0.0.x-beta`としてWindows x64、macOS Apple Silicon、macOS Intelの配布物を生成
- 配布物をCloudflare R2のバージョン付きパスへ置き、公開サイトから参照
- 日本語・英語の操作画面と公開サイトを用意
- 支援導線は配置済みだが未接続

## 公開前に手元で確認すること

- Windows 10または11でインストール、初回起動、再起動、アンインストール
- macOS Apple SiliconとIntelでDMGからの起動手順と警告表示
- OBSで横長・縦長のURL、幅、高さ、透明背景を確認
- 学習、休憩、一時停止、終了、自動切替、終了音を一巡
- 設定と学習時間が再起動後も保持されることを確認
- 公開サイトの日本語・英語ページから各配布物をダウンロード
- 公開サイトに未署名であることと起動手順を明記

## 支援導線を有効化する時

Ko-fiと決済事業者の審査完了後にリンクを接続します。審査完了前は「準備中」のまま公開し、決済URLや審査中のアカウント情報は配布物へ含めません。
